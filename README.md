# GeniLift — сайт

Статический сайт: HTML + CSS + JS, без сборщиков и баз данных.

## Как выложить на GitHub Pages
1. На github.com создайте репозиторий, например `genilift`.
2. Нажмите «Add file → Upload files» и перетащите **всё содержимое** этого архива (не саму папку, а файлы и папки внутри: index.html, site.css, site.js, assets, zapchasti, servis и т.д.). Нажмите «Commit changes».
3. Settings → Pages → Source: «Deploy from a branch», Branch: `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/genilift/`.

Файл `.nojekyll` нужен — не удаляйте его.
