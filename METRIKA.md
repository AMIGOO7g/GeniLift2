# Яндекс Метрика — как подключить и какие цели создать

Сайт уже готов к Метрике: счётчик подключается одним номером, события (цели) отправляются сами. Работает всё только после того, как посетитель нажал «Принять» в баннере cookie, то есть данные покажут не 100% посетителей. Это требование закона и осознанная настройка.

## 1. Создать счётчик (делает владелец, 5 минут)
Сайт для этого запускать не нужно: счётчик создаётся на домен.
1. Войдите на https://metrika.yandex.ru под аккаунтом Яндекса, который будет владельцем (лучше общий, а не личный сотрудника).
2. «Добавить счётчик» → имя «GeniLift», адрес сайта — ваш домен (например `genilift.ru`).
3. Включите: «Карта кликов» (по умолчанию включена в коде), «Точный показатель отказов». «Вебвизор» (запись сессий) **не включайте**, пока это не указано в политике конфиденциальности. В коде он выключен (`metrikaWebvisor: false`).
4. Скопируйте номер счётчика (8–9 цифр).
5. Откройте `config.js` в корне сайта и впишите номер: `metrika: '12345678'`. Сохраните и выложите на сервер. Всё.

## 2. Создать цели (по таблице)
В счётчике: «Настройка» → «Цели» → «Добавить цель» → тип **«JavaScript-событие»**, в поле «Идентификатор цели» — слово из таблицы.

| Идентификатор | Что значит | Основная? |
|---|---|---|
| `lead` | любая заявка с сайта отправлена | **да, главная конверсия** |
| `lead_photo` | заявка из «Подбор по фото» отправлена | да |
| `photo_selected` | посетитель загрузил фото | нет |
| `photo_ocr` | запустил распознавание артикула | нет |
| `photo_ocr_found` | артикул найден в каталоге | нет |
| `add_to_request` | добавил деталь в заявку | да |
| `open_request` | открыл форму заявки | нет |
| `click_phone` | нажал на телефон | да |
| `click_sos` | нажал «Авария 24/7» | да |
| `click_telegram`, `click_whatsapp`, `click_max`, `click_mail` | нажал на мессенджер или почту | да |
| `search_submit` | отправил поиск по артикулу | нет |

Цель типа «Посещение страницы» (URL) для подбора по фото: условие «URL содержит» `/podbor-po-foto/`. Для марок: `/brendy/`.

## 3. Что смотреть
- «Отчёты → Конверсии» по цели `lead`: сколько заявок и с каких страниц.
- «Источники» — откуда приходят те, кто оставил заявку.
- «Содержание → Страницы входа» — какие страницы марок и разделов приводят людей.
- Через месяц: сколько заявок даёт подбор по фото (`lead_photo`) в сравнении с обычной формой.

## 4. Как проверить, что работает
Откройте сайт, нажмите «Принять» в баннере, нажмите на телефон и отправьте тестовую заявку. В Метрике («Отчёты → Мониторинг» или «Цели») события появятся через несколько минут. В адресной строке браузера добавьте `?_ym_debug=1` и откройте консоль — там видны отправки.
