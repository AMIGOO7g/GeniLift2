# GeniLift — как запустить сайт

## 1. Что в архиве
Сайт полностью статический: только файлы, без базы данных и без программ на сервере.

- `index.html` — главная (лифт и этажи)
- `zapchasti/` — лавка: каталог и страница каждой детали
- `servis/` — сервис и 4 страницы услуг
- `o-kompanii/`, `obekty/` — о компании и объекты
- `kontakty/`, `dostavka/`, `korzina/`, `politika/`, `oferta/`
- `assets/` — шрифты, рисунки (`ill/`), лифт (`shaft/`), фото деталей (`parts/`)
- `site.css`, `site.js` — оформление и поведение
- `catalog/products.xlsx` — каталог (источник для сборки)
- `sitemap.xml`, `robots.txt`, `404.html` — для поисковиков и ошибок

Загружается **всё содержимое архива как есть**, с сохранением папок.

## 2. Где разместить (выберите один вариант)

### Вариант А — российский хостинг (рекомендую для клиентов из РФ)
Подойдёт любой: Timeweb, Beget, REG.RU, SpaceWeb.
1. Зарегистрируйтесь и выберите самый простой тариф **«виртуальный хостинг»** (для сайта из файлов хватит минимального).
2. В панели хостинга создайте сайт и привяжите домен `genilift.ru`.
3. Откройте **файловый менеджер** (или подключитесь по FTP, данные — в панели) и загрузите всё содержимое архива в папку сайта (обычно `public_html` или `www/genilift.ru`).
4. В панели включите **бесплатный SSL-сертификат (Let's Encrypt)** и переадресацию на `https://`.
5. Проверьте: https://genilift.ru открывается, ссылки работают, на ПК Ctrl+F5.

### Вариант Б — GitHub Pages (бесплатно, уже настроено)
1. Репозиторий → **Settings → Pages → Custom domain** → `genilift.ru` → Save.
2. У регистратора домена в DNS добавить:
   - 4 записи **A** для `@`: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   - запись **CNAME** для `www` → `amigoo7g.github.io`
3. Через 10–60 минут включить **Enforce HTTPS** в том же разделе.
Минус: серверы за рубежом — у части посетителей из РФ возможны задержки.

## 3. Домен и Тильда
1. Узнайте, где зарегистрирован `genilift.ru` (Reg.ru, Nic.ru и т.д.) — DNS меняются там.
2. После переключения DNS **отвяжите домен в Тильде**, иначе она будет перехватывать адрес.
3. **Переадресация со старых адресов** (301): пришлите список страниц со старого сайта — дам готовый файл `.htaccess` (для варианта А), чтобы позиции в поиске не потерялись.

## 4. Обязательно до запуска

- **Реквизиты** в подвале, политике и оферте (сейчас «ООО «Название»», ИНН нули).
- **Адрес офиса** для карты на странице «Контакты».

## 5. После запуска
1. **Яндекс Вебмастер** (webmaster.yandex.ru): добавить сайт, подтвердить, отправить `https://genilift.ru/sitemap.xml`.
2. **Google Search Console**: то же самое.
3. **Яндекс Метрика**: создать счётчик и прислать мне номер — вставлю код и цели (звонок, заявка, заказ).

## 6. Как обновлять
- **Сайт:** загружаете новый архив поверх старого (заменить все файлы), затем на ПК Ctrl+F5.
- **Каталог:** правите `catalog/products.xlsx` и кладёте фото в `assets/parts/` (имя файла = колонка `photo`) → присылаете мне → получаете новый архив. Когда захотите обновлять без меня — подключим автосборку.
