# Админка каталога — инструкция

Нужна для того, чтобы владелец сам добавлял и менял товары: цены, наличие, фото, описание, скрытие позиций. Excel-файл тоже остаётся: каталог можно загрузить и скачать в .xlsx.

**Админка работает только на хостинге с PHP.** На GitHub Pages PHP не выполняется — там не работают ни админка, ни форма заявок (`send.php`).

## Что нужно от хостинга
- PHP 7.4 или новее (проверено на 8.3) с расширениями `zip`, `gd` (с WebP), `mbstring`, `fileinfo` — обычно они включены.
- Права на запись для PHP в папки: `assets/` (в том числе `assets/parts/`), `zapchasti/`, `admin/data/`, а также в файл `sitemap.xml` и в корень сайта.
- Apache: всё защищено файлами `.htaccess`. **nginx**: добавьте в конфиг `location ^~ /admin/data/ { deny all; }`. Данные и так сохраняются в файлах `*.json.php`, которые браузеру ничего не отдают, но запрет лучше оставить.
- HTTPS — желательно включить до первого входа.

## Первый запуск
1. Откройте `https://ваш-сайт/admin/`. Админка предложит задать пароль.
2. Код установки лежит в файле `admin/data/setup-code.php` на сервере (откройте через FTP или файловый менеджер). После задания пароля файл удаляется.
3. После входа каталог автоматически загружается из `catalog/products.xlsx` (414 позиций, у каждой уже есть страница на сайте).

## Повседневная работа
- **Товары** — список с поиском и фильтрами. «Изменить» открывает карточку, «Скрыть/Показать» снимает позицию с сайта и возвращает её.
- **Цена, наличие, показ, фото** применяются на сайте сразу после «Сохранить и опубликовать» — для старых и новых товаров.
- **+ Добавить** — новый товар. Админка сама создаёт его страницу по образцу существующих, добавляет карточку в каталог, в поиск, в карту сайта и в индекс подбора по фото.
- **Импорт Excel** — файл в формате `catalog/products.xlsx` (или CSV). Товары находятся по `sku`: найденные обновляются, новые добавляются. Пустые ячейки старые значения не стирают, так что можно загрузить файл только с артикулами и ценами. Перед записью показывается предпросмотр.
- **Экспорт** — скачивает весь каталог со всеми правками (Excel или CSV). Его удобно править и загружать обратно.
- **Опубликовать заново** — пересобирает данные сайта из каталога (на случай, если файлы правили руками).
- Копии каталога (последние 30) лежат в `admin/data/backup/`.

## Что админка не делает
- У товаров, страницы которых уже есть на сайте (**старый каталог**), нельзя менять артикул, марку и раздел, а тексты (описание, характеристики) сохраняются в каталоге, но на готовой странице не меняются. Для них работают цена, наличие, скрытие и фото. Такие товары не удаляются, их можно только скрыть.
- Новые разделы и марки создавать нельзя: раздел выбирается из 10 существующих, неизвестная марка попадает в «Другие марки».
- Новые товары попадают в каталог лифтов (`/zapchasti/`), в каталог эскалаторов пока нет.

## Безопасность
Пароль хранится в виде хэша, вход ограничен 5 попытками за 15 минут, формы защищены токеном, загружаемые фото перекодируются, админка закрыта от поисковиков (`robots.txt`, заголовки). Файл с паролем и каталогом в git не попадает (`.gitignore`).
